Adopted the observability setup from the `copier-python-service` template.
Every request now emits a single JSON log line carrying the method, path, status, duration and a `request_id`,
and Prometheus metrics are served from `/metrics`.
This also adds the operational routes the template ships:
`/livez` and `/readyz` for orchestrator probes, and `/deploy/info` for the image build stamps.
Set `LOG_FORMAT=text` for readable logs during local development.
